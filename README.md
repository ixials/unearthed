# Unearthed

Unearthed is a live museum collecting archaeological and paleontological news from around the world. Deployed on [Vercel](https://un-earthed.vercel.app/) <3

## Contributing

Pull requests are welcome! Make sure to install the requirements:

```bash
pip install -r requirements.txt
```
